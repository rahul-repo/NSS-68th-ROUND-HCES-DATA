# HCES Data Comparison: West Bengal vs Assam (2025)

## Overview

This project presents a statistical analysis of socio-economic and consumption patterns using 68th Round Household Consumption Expenditure Survey (HCES) microdata. The study compares West Bengal and Assam using survey-based inference methods.

The objective is to understand regional differences in expenditure behavior, dietary patterns, and socio-economic indicators.

---

## Project year: 2025

## Objectives

* Compare consumption patterns across West Bengal and Assam
* Analyze MPCE (Monthly Per Capita Expenditure) differences
* Study food consumption behavior (cereal and non-vegetarian intake)
* Examine behavioural indicators such as addiction patterns
* Assess socio-economic variation across groups

---

## Data

The analysis uses HCES 68th Round microdata including:

* Household consumption expenditure (MPCE)
* Food consumption categories
* Social group classification
* Demographic characteristics
* Behavioural indicators
